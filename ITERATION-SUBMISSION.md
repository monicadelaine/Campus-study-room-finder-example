# Iteration Submission Snapshot

The LMS submission is a point-in-time snapshot. GitHub remains the authoritative project record.

## Submit / Link
- Product Backlog view
- Iteration N Plan view
- Iteration N Results view
- Team Contributions view
- Engineering & Quality Work view
- Remaining Backlog view
- Three formal stand-up Issues
- `course/iterations/iteration-N/planning.md`
- `course/iterations/iteration-N/review.md`
- `course/iterations/iteration-N/retrospective.md`
- iteration presentation PDF under `course/presentations/`
- current required handoff documentation under `docs/`
- repository URL and GitHub Project URL
- annotated repository tag: `iteration-N-submission`

Incomplete and blocked work must remain visible. Done items should contain appropriate completion evidence.

The repository tag freezes repository content at the deadline. Project-view snapshots/links preserve the Project/Issue state, which is not frozen by a Git tag.
